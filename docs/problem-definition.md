# 데이터 분석 문제 정의

## 오늘의 문제 정의 요약

### 1. 이 데이터를 고른 이유
- 서울 일별 기상 데이터가 1994~2024년 30년치, 결측 없이 매일 기록돼 있어 다루기 안정적이다.
- 비는 누구나 익숙한 현상이라 예측 결과가 맞았는지 틀렸는지 직관적으로 판단하기 쉽다.
- 앞서 자전거 대여량 프로젝트에서 만든 회귀 비교 구조(스크립트 번호·outputs 3분류)를 그대로 재사용할 수 있다.

### 2. 오늘 풀 문제
- **"내일 비가 올지"**, 그리고 **"온다면 얼마나 올지"**를 예측한다.
- 오늘(t)까지의 날씨 정보로 내일(t+1)의 강수 여부·강수량을 맞추는 문제다 — 당일 값(예: `precip(t+1)`)은 입력에 쓰지 않는다.
- 순서: 1번(강수 발생 여부, 분류) → 2번(강수량, 회귀) → 3번(기대 강수량, 결합) 순으로 확장한다.

### 3. 오늘 데이터에서 확인해볼 것 3가지
1. **강수 발생 비율** — 비/눈 온 날이 전체의 몇 %인지 (한쪽으로 너무 쏠리면 분류 모델 성능 해석에 주의 필요)
2. **입력 후보 변수의 예측력** — `precipprob`, `cloudcover`, `humidity` 등이 다음날 강수 여부·양과 실제로 상관관계가 있는지
3. **계절성** — 월별·계절별로 강수 패턴이 뚜렷한지(장마철 vs 겨울) — 뚜렷하면 월/계절 변수를 입력에 추가할지 판단 근거가 됨
